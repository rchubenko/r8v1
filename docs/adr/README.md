# ADR R8 v1

Только перечисленные здесь ADR являются активными источниками истины R8 v1.

| ADR | Решение | Статус |
|---|---|---|
|---|---|---|
| [ADR-0001](0001-unified-memory.md) | Единая память объёмом 4 КБ | Принято |
| [ADR-0002](0002-software-first-codesign.md) | Совместная разработка от программной модели | Принято |
| [ADR-0003](0003-eeprom-control-unit.md) | Микрокодовый блок управления на EEPROM | Принято |
| [ADR-0004](0004-separate-address-path.md) | Отдельный 12-разрядный адресный тракт | Принято |
| [ADR-0005](0005-flags-update-on-a-write.md) | Обновление FLAGS при записи в A | Принято |
| [ADR-0006](0006-reset-architecture.md) | Архитектура RESET | Принято |
| [ADR-0007](0007-memory-ownership.md) | Исключительное владение SRAM | Принято |
| [ADR-0008](0008-reserved-opcodes.md) | Резервирование opcode `0xB`–`0xE` | Принято |
| [ADR-0009](0009-clock-transition.md) | Стратегия перехода тактового сигнала | Принято |
| [ADR-0010](0010-deterministic-software-model-semantics.md) | Детерминированная семантика software models | Принято |

Новый ADR, заменяющий прежнее решение, обязан явно указать заменяемый ADR (`supersedes`). Конфликтующие ADR не могут одновременно оставаться активными.
