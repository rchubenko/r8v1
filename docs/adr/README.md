# ADR R8 v1

Только перечисленные здесь ADR являются активными источниками истины R8 v1.

| ADR | Decision | Status |
|---|---|---|
| ADR | Решение | Статус |
|---|---|---|
| [ADR-0001](0001-unified-memory.md) | Unified 4 KB Memory | Accepted |
| [ADR-0002](0002-software-first-codesign.md) | Software-First Co-Design | Accepted |
| [ADR-0003](0003-eeprom-control-unit.md) | EEPROM Microcoded Control Unit | Accepted |
| [ADR-0004](0004-separate-address-path.md) | Separate 12-Bit Address Path | Accepted |
| [ADR-0005](0005-flags-update-on-a-write.md) | FLAGS Update on Accumulator Write | Accepted |
| [ADR-0006](0006-reset-architecture.md) | Reset Architecture | Accepted |
| [ADR-0007](0007-memory-ownership.md) | Exclusive SRAM Ownership | Accepted |
| [ADR-0008](0008-reserved-opcodes.md) | Reserve Opcodes 0xB Through 0xE | Accepted |
| [ADR-0009](0009-clock-transition.md) | Clock Transition Strategy | Accepted |
| [ADR-0010](0010-deterministic-software-model-semantics.md) | Deterministic Software Model Semantics | Accepted |

Новый ADR, заменяющий прежнее решение, обязан явно указать superseded ADR. Конфликтующие ADR не могут одновременно оставаться активными.
