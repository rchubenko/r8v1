# Task M2-012: Implement SUB

## Summary

Добавлено atomic SUB execution после fetch. SUB читает актуальный byte из state-owned SRAM по полному 12-bit operand, переиспользует approved stateless ALU и загружает modulo-256 результат в A с полностью определёнными FLAGS.

## Scope

В scope входят только SUB execution после supplied `DecodedInstruction`, full 12-bit SRAM addressing, modulo-256 result, no-borrow C, Z/C/S/O update и preservation остальных architectural fields. STA, branches, HALT, dispatcher, microsteps и hardware execution не реализуются.

## Design decision

`ArchitecturalState.execute_instruction()` получил отдельную ветку `Opcode.SUB`:

```text
operand_value = SRAM.read(instruction.operand)
alu_result = evaluate(ALUMode.SUB, A, operand_value)
A <- alu_result.result
FLAGS <- latch_flags_for_alu_write(alu_result)
```

Используется unified stateless ALU из `cpu/`. Arithmetic, modulo-256 result, no-borrow carry, zero, sign и signed overflow не дублируются в `emulator/`. Persistent B register, `control word` decode и physical B-load sequence отсутствуют.

## FLAGS behavior

После SUB сохраняются значения approved ALU:

- Z определяется из modulo-256 result;
- C равен `1`, если A >= operand и borrow отсутствует;
- S определяется bit 7 result;
- O определяется signed overflow для SUB.

`latch_flags_for_alu_write()` устанавливает `flags_defined_mask = Z | C | S | O` независимо от предыдущего mask и concrete FLAGS.

## State preservation

После fetch SUB изменяет только A и FLAGS/mask. PC остаётся post-fetch, IR и SRAM сохраняются, HALT не изменяется. Operand byte читается из SRAM при каждом execution и не кэшируется.

## Tests

Проверены:

- boundary result cases, включая zero, borrow wraparound, sign и maximum operands;
- no-borrow C для равных operands, A больше operand, A меньше operand, zero subtraction и sign boundaries;
- signed overflow и отсутствие overflow на representative cases;
- Z/S для zero, positive, sign-bit и wraparound results;
- все пары `A = 0x00..0xFF` и operand byte `0x00..0xFF` через emulator execution boundary, всего `256 x 256` combinations;
- все initial `flags_defined_mask` variants: none, Z/S, C/O и all defined;
- full 12-bit operand addresses `0x000`, `0x001`, `0x0FF`, `0x100`, `0xABC`, `0xFFE`, `0xFFF`;
- current SRAM value при repeated SUB после изменения memory;
- PC/IR/SRAM/HALT preservation;
- SUB instruction fetch boundary `0xFFF -> 0x000` с post-fetch PC `0x001`;
- NOP, LDI, LDA и ADD regression, а также unsupported STA rejection without mutation.
