# Task M2-014: Implement JMP

## Summary

Добавлено atomic unconditional JMP execution после fetch. JMP загружает PC точным 12-bit operand и сохраняет остальные architectural fields и FLAGS state.

## Sources

Работа сверена с [`AGENTS.md`](../../../AGENTS.md), [README проекта](../../../README.md), [архитектурой](../../architecture.md), [ISA](../../isa.md), [микроархитектурой](../../microarchitecture.md), [Control Word](../../control-word.md), [memory](../../memory.md), [software testing policy](../../testing/software.md), [планом Milestone 2](../../plans/milestone-2-isa-reference-emulator.md), [execution contract M2-002](002-emulator-execution-contract.md), reports M2-003 through M2-013, [ADR-0001](../../adr/0001-unified-memory.md), [ADR-0010](../../adr/0010-deterministic-software-model-semantics.md), existing ProgramCounter API и emulator test conventions.

## Scope

В scope входят только JMP execution после supplied `DecodedInstruction`, exact full 12-bit PC target, odd-address support и preservation остальных architectural fields/FLAGS. Conditional branches, diagnostics, HLT, reserved opcode halt, dispatcher, microsteps и hardware execution не реализуются.

## Design decision

`ArchitecturalState.execute_instruction()` получил отдельную ветку `Opcode.JMP`:

```text
PC <- instruction.operand
```

Используется existing 12-bit `ProgramCounter.load()` API. Relative addressing, alignment normalization и fetch-contract changes отсутствуют.

## State preservation

После fetch JMP изменяет только PC. A, IR, SRAM, concrete FLAGS, `flags_defined_mask` и HALT сохраняются. JMP не вызывает FLAGS policy.

## Tests

Проверены:

- representative targets `0x000`, `0x001`, `0x002`, `0x0FF`, `0x100`, `0xABC`, `0xFFE`, `0xFFF`;
- odd targets `0x001`, `0x123`, `0xFFF` без alignment requirement;
- concrete FLAGS combinations и masks none, Z/S, C/O, all;
- A, IR, SRAM и HALT preservation;
- post-fetch PC transition before target load;
- JMP instruction fetched через `0xFFF -> 0x000` с post-fetch PC `0x001`;
- existing NOP, LDI, LDA, ADD, SUB и STA regression, а также reserved-opcode halt coverage.
