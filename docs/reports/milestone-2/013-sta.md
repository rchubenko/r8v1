# Task M2-013: Implement STA

## Summary

Добавлено atomic STA execution после fetch. STA записывает текущее значение A в state-owned SRAM по полному 12-bit operand, изменяет только addressed byte и полностью сохраняет FLAGS state.

## Scope

В scope входят только STA execution после supplied `DecodedInstruction`, full 12-bit SRAM addressing, exactly-one-byte write, current A observation и preservation architectural fields/FLAGS. Memory ownership, `RAM_WE`, electrical timing, MAR, DATA BUS и physical write sequence не реализуются.

## Design decision

`ArchitecturalState.execute_instruction()` получил отдельную ветку `Opcode.STA`:

```text
SRAM.write(instruction.operand, A)
```

Используется существующий validated `SRAM.write()` API. Он принимает полный 12-bit address и изменяет ровно одну storage location. STA не вызывает FLAGS latch policy и не пересчитывает flags.

## Memory behavior

- operand используется без маскирования и поддерживает `0x000..0xFFF`;
- записывается ровно один byte, равный текущему A;
- запись в code addresses разрешена;
- self-modifying code сохраняется: последующий fetch видит изменённый byte;
- same-value write оставляет logical memory image неизменным.

## FLAGS behavior

STA сохраняет concrete `Z`, `C`, `S`, `O` и `flags_defined_mask` для всех проверенных initial combinations. STA не вызывает `latch_flags_for_alu_write()`, `latch_flags_for_non_alu_write()` или другую flags policy.

## State preservation

После fetch STA изменяет только `SRAM[instruction.operand]`. A, PC, IR, FLAGS, `flags_defined_mask` и HALT сохраняются. A читается в момент execution, поэтому изменение A после fetch наблюдается записью.

## Tests

Проверены:

- representative addresses `0x000`, `0x001`, `0x0FF`, `0x100`, `0xABC`, `0xFFE`, `0xFFF`;
- representative A values `0x00`, `0x01`, `0x7F`, `0x80`, `0xFF`;
- exactly-one-byte change на non-trivial full 4096-byte image;
- same-value write с неизменным logical memory image;
- concrete FLAGS combinations `0000`, `0001`, `0010`, `0100`, `1000`, `1111` и masks none, Z/S, C/O, all;
- current A observation после fetch;
- A/PC/IR/FLAGS/mask/HALT preservation;
- code-address write и self-modifying future fetch;
- STA instruction fetch boundary `0xFFF -> 0x000` с post-fetch PC `0x001`;
- NOP, LDI, LDA, ADD и SUB regression, а также unsupported JMP rejection without mutation.

## Architectural compliance

Implementation находится в `emulator/` и переиспользует existing SRAM write API. Не добавлены `MEM_OWNER`, `RAM_WE`, electrical timing, MAR, DATA BUS, microsteps, clock, simulator, assembler, loader, write protection или hardware coupling. Self-modifying code и code-address writes разрешены согласно memory contract. JMP и остальные unsupported instructions остаются за пределами задачи.
