# Task M2-010: Implement LDA

## Summary

Добавлена atomic LDA execution после fetch. LDA читает актуальный byte из state-owned SRAM по полному 12-bit operand, загружает его в A и применяет approved partial FLAGS policy LDI/LDA.

## Scope

В scope входят только LDA execution после supplied `DecodedInstruction`, full 12-bit SRAM addressing, current memory observation, A load и partial FLAGS update. MAR, DATA BUS, memory cycles, clock и остальные instructions не реализованы.

## Design decision

`ArchitecturalState.execute_instruction()` получил отдельную ветку `Opcode.LDA`:

```text
loaded = SRAM.read(instruction.operand)
A <- loaded
FLAGS <- latch_flags_for_non_alu_write(loaded, previous C, previous O)
```

Operand не маскируется и используется в полном диапазоне `0x000..0xFFF`. Existing unsupported-opcode behavior сохраняется для ADD, SUB и других неподдерживаемых instructions.

## FLAGS behavior

LDA переиспользует `latch_flags_for_non_alu_write()`:

- Z вычисляется из loaded byte;
- S берётся из bit 7 loaded byte;
- concrete C/O сохраняются;
- `flags_defined_mask` становится `Z | S`.

## State preservation

После fetch LDA изменяет только A и FLAGS/mask. PC остаётся post-fetch, IR и SRAM сохраняются, HALT не изменяется. LDA читает актуальный SRAM byte без caching.

## Tests

Проверены:

- addresses `0x000`, `0x001`, `0x07F`, `0x080`, `0x0FF`, `0x100`, `0xABC`, `0xFFE`, `0xFFF`;
- loaded values `0x00`, `0x01`, `0x7F`, `0x80`, `0xFF` и Z/S;
- все combinations concrete C/O;
- current SRAM value при repeated LDA;
- PC/IR/SRAM/HALT preservation;
- LDA instruction fetch boundary `0xFFF -> 0x000`;
- unsupported ADD/SUB rejection without mutation.
